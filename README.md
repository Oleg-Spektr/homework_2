# E-commerce Core Project

Инструмент для управления сущностями интернет-магазина (категориями и товарами). Проект разработан в рамках изучения основ объектно-ориентированного программирования (ООП) на Python с применением методологии разработки GitFlow.

## Реализованный функционал
- **Класс `Product`**: хранит информацию о товаре (название, описание, цена, количество на складе).
- **Класс `Category`**: группирует товары, хранит список встроенных объектов `Product` и автоматически собирает сквозную статистику.
- **Подсчет метрик**: автоматический расчет общего числа категорий и уникальных товаров в системе без дублирования данных.
- **Импорт данных**: реализована функция инициализации объектов классов напрямую из внешнего файла конфигурации JSON.

## Технологический стек
- **Язык**: Python 3.10+
- **Менеджер зависимостей**: Poetry
- **Качество кода (Линтеры)**: Ruff (PEP 8 форматирование и статический анализ)
- **Тестирование**: Pytest (покрытие фикстурами и ассертами)

## Как запустить тесты
```bash
poetry run pytest
```
