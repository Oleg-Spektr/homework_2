## Электронная коммерция (Тема: Абстрактные классы и миксины)

В рамках текущего этапа разработки было реализовано:
- **Абстрактный базовый класс**: создан класс `BaseProduct` (на основе модуля `abc`), который стал родителем для `Product`. Прямая инициализация абстрактного класса невозможно.
- **Класс-миксин**: реализован миксин `PrintMixin`, который автоматически логирует в консоль информацию о создании любого объекта-продукта (его класс и переданные параметры).
- **Дополнительное задание**: выделен общий абстрактный класс `BaseGroup` для группировок, от которого унаследованы класс `Category` и новый созданный класс `Order` (Заказ).
- **Тестирование**: добавлены unit-тесты, проверяющие логику абстрактных классов, новые сущности и вывод миксина в поток `stdout`. Общее покрытие тестами составляет более 75%.
