## Электронная коммерция (Тема: Обработка исключений)

В рамках текущего этапа разработки было реализовано:
- **Пользовательское исключение**: создан класс `ZeroQuantityError` (наследуется от `ValueError`) для обработки ситуаций с добавлением или заказом товаров с нулевым количеством.
- **Генерация исключений**: в абстрактном классе `BaseProduct` настроена проверка `quantity == 0`, вызывающая кастомную ошибку.
- **Конструкция try-except-else-finally**: метод `add_product` класса `Category` и инициализатор класса `Order` дополнены блоками для перехвата исключений, логирования успешных операций («Товар добавлен») и гарантированного вывода финального сообщения («Обработка добавления товара завершена»).
- **Обработка ZeroDivisionError**: в классе `Category` реализован метод `middle_price()`, возвращающий среднюю цену товаров. Если категория пуста, деление на ноль перехватывается, и метод безопасно возвращает `0.0`.
- **Тестирование**: добавлены тесты в `tests/test_ecommerce.py` для полной проверки генерации и перехвата всех исключений.
