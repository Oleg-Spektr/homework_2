## Электронная коммерция (Тема: Наследование)

В рамках текущего этапа разработки было реализовано:
- **Наследование классов**: созданы подклассы `Smartphone` и `LawnGrass`, расширяющие базовый класс `Product` специфичными атрибутами.
- **Валидация типов при добавлении**: метод `add_product` класса `Category` теперь принимает только объекты класса `Product` или его наследников. При попытке добавить некорректный объект выбрасывается ошибка `TypeError`.
- **Строгая проверка при сложении товаров**: метод `__add__` класса `Product` изменен так, чтобы можно было складывать только товары одного и того же класса через функцию `type()`.
- **Тестирование**: добавлены модульные тесты для проверки всей новой функциональности с помощью `pytest`.
